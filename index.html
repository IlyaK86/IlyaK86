🦉

OWL — Оркестратор

Главный агент-координатор. Принимает задачи от пользователя, декомпозирует их и делегирует специализированным агентам. Управляет памятью, расписанием и интеграциями.

Активен
📈

Sales Forecaster

Прогнозирование продаж на базе ML (LightGBM, XGBoost, Prophet). 68 признаков временных рядов, ансобучение, автоматическая калибровка и диагностика моделей с SHAP-анализом.

Активен
💻

Coding Agent (Pi + OpenCode)

Автоматизированная разработка кода. Pi CLI и OpenCode работают как субагенты — пишут функции, правят баги, создают скрипты обработки данных. Модели — бесплатные ($0).

Активен

🗺 Roadmap — Что будет добавлено

Планы развития и новые возможности

📊

Интерактивный дашборд

Визуализация прогнозов в реальном времени: графики временных рядов, feature importance, остатки модели. Интеграция с OWL Office v2.

🔔

Уведомления и алерты

Автоматические уведомления в Telegram при аномалиях: отклонение факта от прогноза >30%, новые данные, ошибки модели.

🤖

Автообновление моделей

Ежеднедельный реtrain на свежих данных, A/B тестирование версий модели, автовыбор лучшей по WAPE.

🔗

Битрикс24 интеграция

Автоматический импорт данных из CRM, выгрузка прогнозов обратно, создание сделок на основе прогноза спроса.

🧠

Улучшение модели

Борьба с bias: post-hoc калибровка, отдельные модели для Russia/CIS, обработка новых продуктов (cold start), добавление внешних регрессоров.

📱

Голосовой интерфейс

Задать вопрос голосом → Whisper STT → LLM анализ → голосовой ответ через TTS. Локально, без облака, на русском языке.
